# 今天吃什么（转盘）

纯静态页面，双击 `index.html` 即可本地打开，无需安装任何东西。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `style.css` | 样式（浅蓝主题） |
| `app.js` | 转盘绘制、转动动画、指针读数、弹窗 |
| `foods.js` | **选项数据**（要增删食物 / 填介绍只改这个文件） |
| `tools/export_foods.py` | 从 `食物.xlsx` 重新导出 `foods.js` 的脚本 |
| `README.md` | 本说明 |

## 一、本地增删选项

打开 `foods.js`，格式是「分类 -> 条目数组」，每条一行：

```js
window.FOOD_DATA = {
  "主食类": [
    {"name": "清汤面", "mid": "煮制类", "sub": "面条", "desc": ""},
    ...
  ],
  "菜品类": [ ... ],
  "饮料":   [ ... ],
  "甜点":   [ ... ],
  "零食小吃": [ ... ]
};
```

- **加一项**：在对应分类里加一行 `{"name": "小笼包", "mid": "蒸制类", "sub": "带馅", "desc": ""}`
- **删一项**：删掉那一行
- **加分类**：新增一个键，顶部会自动出现对应按钮
- `mid` 是中类（煮制类、烤制类、酒…），`sub` 是小类（面条、中式烤制、啤酒…）
- 页面显示顺序固定为 **分类 · 中类 · 小类**（例如「主食类·烤制类·中式烤制」），为空的层级自动跳过
- `desc` 是该食物的介绍，点结果弹窗时显示；**留空则显示占位文案**

改完保存，刷新页面生效（缓存时 Ctrl+F5）。
当前数据：主食 150 / 菜品 144 / 饮料 110 / 甜点 156 / 零食小吃 80，共 640 项。

### 从表格重新导入（含介绍文案）

1. 把介绍表格放到桌面，第一列「食物名」，第二列「介绍」
2. 编辑 `tools/export_foods.py` 顶部的 `DESC_XLSX = r'...表格路径...'`
3. 运行 `python tools/export_foods.py`，会重新生成 `foods.js` 并把介绍自动填进 `desc`

## 二、交互说明

- **顶部分类可多选**：同时勾选主食 + 菜品 + 饮料，这三类就合并进选项池；
  「全选」一键全勾；至少保留一类（最后一个不可取消）
- 转盘上方大字**实时显示指针当前指向的选项**，转动时快速滚动
- 点「开始」转动，转动中再点「停止」提前收尾；停下后上方显示「今天吃 XXX」
- **停下后点上方卡片**弹出结果窗口：固定尺寸，食物名称 + 介绍，
  文字超长时窗口内部可上下滑动；底部「再转一次」直接开下一轮
- 右侧竖条「选项」按钮可随时拉开/收起侧栏，查看当前选项池的全部条目
- 选项太多、扇区太窄时转盘标签会自动隐去（只留色块），不影响抽取

## 三、部署到 GitHub Pages（后续）

1. 在 GitHub 新建仓库（例如 `food-wheel`），把这些文件推上去
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)` → Save
3. 等一两分钟，访问 `https://<用户名>.github.io/food-wheel/`

### 绑定自己的域名

1. 仓库根目录放 `CNAME` 文件（无后缀），内容只写一行域名，如 `eat.example.com`
2. 域名解析商处添加 CNAME 记录：`eat` → `<用户名>.github.io`
3. Pages 设置页 Custom domain 填同样域名，勾 Enforce HTTPS
